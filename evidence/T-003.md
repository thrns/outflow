Its self-contained `--demo` uses only synthetic text; it does not load audio, model files, dataset files, or fixture references, and it writes no results. ## Aggregate synthetic corpus WER checkpoint — 2026-10-30

Added `scripts/score_corpus_wer.py`, which scores each in-memory reference/prediction pair through the existing `scripts/score_wer.py` calculator and sums its alignment counts. Corpus WER is total substitutions + deletions + insertions divided by total reference words; the individual percentages are not averaged. The result reports utterances scored, reference words, each edit count, edit distance, and numeric WER fraction. An empty collection or any empty normalized reference raises `ValueError`; silence/no-speech scoring remains separate. The existing individual calculator and normalization rules were not changed.

Added 17 standard-library `unittest` cases in `scripts/tests/test_score_corpus_wer.py`. The complete Python suite passed all 57 tests, preserving the prior 40. The demo's 100% and 0% individual samples aggregate to 10% corpus WER because there is one error across ten reference words.
