Its self-contained `--demo` uses only synthetic text; it does not load audio, model files, dataset files, or fixture references, and it writes no results. The fixture policy already specifies NFC, lowercase, collapsed whitespace, punctuation-free lexical WER, and separate punctuation evaluation. It does not fully define Unicode token boundaries. For this synthetic utility, `provisional-unicode-boundary-v1` treats runs of Unicode letters, numbers, and combining marks as tokens and punctuation/other characters as boundaries. This choice is documented in the README and code; it is not a frozen benchmark policy. The rule must be reviewed and frozen before any corpus WER run.
